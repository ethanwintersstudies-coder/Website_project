# Web Dev Quiz

A browser quiz app with 10 HTML, CSS and JavaScript questions. Built with plain HTML, CSS and JavaScript, no libraries.

## Features
- 10 questions stored in an array of objects, drawn by JavaScript
- One question at a time, "Question 3 of 10" counter and progress bar
- Green for correct and red for wrong; buttons lock after answering
- Result screen with score, percentage, message, review list and Restart
- **Extras:** Dark/Light mode (remembered), best score saved in localStorage, keyboard shortcuts (1-4 and Enter), shuffled questions and options
- Responsive layout for phones

## Files
- `index.html`: page structure (start, quiz and result screens)
- `style.css`: styling, colour variables and dark mode
- `script.js`: all quiz logic

## Run
Open `index.html` in a browser.

## Deploy
Push to GitHub, then import the repo in Netlify or Vercel (no build command).
